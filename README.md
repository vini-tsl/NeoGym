# NeoGym

O NeoGym é uma aplicação web pensada para ajudar pessoas a treinarem de forma mais acessível, informada e consistente oferecendo orientação e acompanhamento para apoiar a evolução muscular do usuário ao longo do tempo.

## Sobre o projeto

Muita gente quer começar a treinar, mas esbarra em falta de acessibilidade, orientação ou noção de como estruturar os treinos. O NeoGym busca resolver isso oferecendo uma experiência simples e guiada, ajudando o usuário a entender seus treinos e acompanhar sua evolução.

## Tecnologias utilizadas

- [HTML5]
- [CSS3]
- [JavaScript]
